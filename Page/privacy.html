Politique de confidentialité

Dernière mise à jour : 21 août 2026

Bienvenue

Cette politique de confidentialité explique quelles données peuvent être collectées lorsque vous utilisez le site mezzmonteur.com, pourquoi elles sont utilisées et comment elles sont traitées.

1. Données collectées

Lorsque le système de suivi est actif, les informations suivantes peuvent être collectées :

  • 🌐 Adresse IP publique
  • 📄 Page visitée
  • 🌍 Navigateur utilisé
  • 💻 Système d'exploitation
  • 🖥️ Résolution de l'écran
  • 🗣️ Langue du navigateur
  • 🕐 Date et heure de la visite

Ces informations sont collectées à des fins de statistiques, de suivi de fréquentation et d'amélioration du site.

2. Finalité de la collecte

Les données peuvent être utilisées pour :

  • connaître la fréquentation du site ;
  • savoir quelles pages sont consultées ;
  • comprendre les caractéristiques techniques générales des visiteurs ;
  • détecter d'éventuels problèmes techniques ;
  • améliorer le site et son fonctionnement.

Les données collectées ne sont pas destinées à être vendues à des tiers.

3. Consentement

Lorsque le site utilise un mécanisme de consentement, le suivi est activé uniquement après l'acceptation de l'utilisateur.

L'utilisateur peut refuser le suivi lorsque cette possibilité lui est proposée.

Le choix effectué peut être conservé dans le navigateur afin d'éviter de demander à nouveau le consentement à chaque visite.

4. Services tiers

Les données collectées peuvent être transmises à des services tiers utilisés pour assurer le fonctionnement du système de statistiques.

Le site utilise notamment Discord pour recevoir les notifications générées par le système de suivi.

Certaines informations collectées peuvent donc être transmises à Discord par l'intermédiaire d'un webhook.

Le site utilise également ipify afin d'obtenir l'adresse IP publique du visiteur lorsque le tracker est actif.

5. Adresse IP

L'adresse IP peut être collectée afin d'identifier techniquement une visite et de fournir des statistiques de fréquentation.

L'adresse IP n'est pas utilisée pour tenter d'identifier directement une personne physique.

6. Conservation des données

Les données collectées peuvent être conservées pendant la durée nécessaire aux finalités décrites dans cette politique.

La durée exacte de conservation peut notamment dépendre du service utilisé pour recevoir ou stocker les informations.

7. Sécurité

Des mesures raisonnables sont mises en place afin de protéger les informations collectées contre les accès ou utilisations non autorisés.

Cependant, aucune transmission de données sur Internet ne peut être considérée comme totalement sécurisée.

8. Vos droits

Lorsque la réglementation applicable, notamment le RGPD, vous accorde ces droits, vous pouvez notamment demander :

  • l'accès à vos données ;
  • la rectification de données inexactes ;
  • l'effacement de vos données ;
  • la limitation du traitement ;
  • vous opposer à certains traitements ;
  • retirer votre consentement lorsque le traitement repose sur celui-ci.

Pour toute demande concernant vos données personnelles ou cette politique, vous pouvez contacter le responsable du site via le moyen de contact disponible sur mezzmonteur.com.

10. Modifications

Cette politique de confidentialité peut être modifiée à tout moment afin de tenir compte des évolutions du site, des services utilisés ou de la réglementation applicable.

La date de dernière mise à jour est indiquée en haut de cette page.

En utilisant le site, vous pouvez consulter cette politique afin de comprendre comment les données liées à la navigation peuvent être traitées.
