Politique de confidentialité

Dernière mise à jour : 29 juillet 2026

1. Présentation et responsable de traitement

Cette politique de confidentialité explique comment le site Mezz — Monteur Vidéo & Sound Designer collecte, traite et conserve les données de fréquentation à des fins d'analyse d'audience et de mesure de performance.

2. Données collectées

Lors de votre visite sur le site (sous réserve de votre consentement), les données suivantes sont enregistrées :

  • Date et heure : horodatage exact de chaque consultation ;
  • Page consultée : chemin d'accès (ex. /, /dashboard/) ;
  • Adresse IP complète : adresse IP du visiteur pour la sécurité et l'analyse géographique ;
  • Ville et pays : localisation géographique basée sur la requête réseau ;
  • Navigateur : nom du logiciel de navigation (Chrome, Firefox, Safari, Edge, etc.) ;
  • Appareil : type d'équipement (Desktop, Mobile, Tablette) ;
  • Provenance (Referrer) : origine du trafic (Direct, Moteur de recherche, site référent).

3. Durée de conservation (365 jours)

Les données de visite enregistrées en base de données Cloudflare D1 et localement sont conservées pendant une durée maximale de 365 jours (1 an). Un nettoyage automatique quotidien supprime définitivement toute donnée antérieure à cette période.

4. Finalité et base légale

La collecte de ces statistiques permet d'évaluer la fréquentation du portfolio, de détecter d'éventuelles anomalies réseau et d'optimiser l'expérience utilisateur. La base légale de ce traitement est votre consentement libre et éclairé (Article 6.1.a du RGPD).
